# README Architect

README Architect is a powerful automation tool designed to streamline the process of creating professional GitHub documentation for Python projects. By leveraging the Gemini CLI, it intelligently analyzes your source code and generates a comprehensive `README.md` file, saving developers time and ensuring high-quality project presentation.

## Features

- **Automated Code Analysis**: Scans your local directory for Python files and extracts relevant code context.
- **AI-Powered Documentation**: Utilizes the Gemini CLI to generate descriptive, professional, and well-structured Markdown content.
- **Surgical Extraction**: Automatically ignores its own source code (`architect.py`) to focus solely on your project's logic.
- **Instant Output**: Generates a `README_GENERATED.md` file ready for review and integration.

## How it Works

The tool performs the following steps:
1. **Discovery**: Identifies all `.py` files in the current working directory.
2. **Context Aggregation**: Reads the contents of each file to build a complete picture of the codebase.
3. **AI Processing**: Pipes the aggregated code into the Gemini CLI with a specialized prompt for README generation.
4. **Delivery**: Saves the resulting Markdown text to a new file.

## Usage

### Prerequisites

- Python 3.x
- [Gemini CLI](https://github.com/google/gemini-cli) installed and configured in your system path.

### Running the Architect

1. Place `architect.py` in the root directory of your Python project.
2. Execute the script via your terminal:

```bash
python architect.py
```

3. Once the process completes, your new documentation will be available in `README_GENERATED.md`.

## Example Components

The repository includes sample files to demonstrate analysis capabilities:
