#  README Architect 

> Built for the **European Summer Hackathon (Paris, 2026)**.  
> An AI automation tool that turns raw code into professional project documentation in seconds.

##  The Problem
During a hackathon, every minute counts. Developers often skip writing the README, which makes it hard for judges to see the project's value. **README Architect** uses Gemini AI to scan your codebase and write the documentation for you.

## Features
* **Auto-Scanning**: Detects your Python scripts automatically.
* **Intelligent Summarization**: Uses Gemini to explain *why* your code matters, not just *what* it does.
* **Zero-Copy Workflow**: Stays entirely in your terminal.

##  How to Use
1. Clone this repo.
2. Ensure you have the `gemini-cli` installed.
3. Run `python architect.py`.

##  Tech Stack
- **Language**: Python
- **AI**: Gemini 1.5 via Google CLI
- **Platform**: Cross-platform (Windows/macOS/Linux)
